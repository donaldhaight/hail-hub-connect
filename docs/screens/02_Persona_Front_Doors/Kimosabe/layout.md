# Layout

**Unopened.** One screen, vertically centred, nothing else. Wordmark large in serif, eyebrow
beneath in small caps, one field with a search affordance, one button. No header, no nav, no
footer links competing with the field. The whole page is the invitation to type once.

**Opened.** The same page, in place — no navigation, no reload. The question is echoed back,
then the promise, then the file: anchor acknowledged, wallet balance, the earn schedule as
gestures, the entry price, and the way to become a member. The ask field stays, moved down,
with the returning placeholder.

On a phone the whole thing is a single column; the field never falls below the fold on first
paint.
