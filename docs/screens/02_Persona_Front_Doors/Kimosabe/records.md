# Permitted records

| Record | Scope | Shown | Hidden and why |
|---|---|---|---|
| Anonymous file (anchor) | the browser's own anchor, held in local storage | that it exists, and when it opened | the anchor value itself is opaque — it is an identifier, not a name |
| Holding wallet | that anchor's balance | JoeBack balance, entry price | nothing about other people, ever |
| Ledger entries | that anchor's own lines | reason label, amount, direction | no aggregate, no other anchor, no platform totals |

No property record, no lead, no person's name, no email. Nothing is asked for and nothing is
stored that the person did not type.

**Provenance:** this door is one of the three lead sources, and the only one it names. How
an address might otherwise be reached is band 3 and appears nowhere on this screen.
