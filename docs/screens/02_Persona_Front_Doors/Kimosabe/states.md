# States

| State | When | What the person sees |
|---|---|---|
| Unopened | no anchor in storage, nothing asked | wordmark, eyebrow, one field, one button |
| Returning | an anchor is in storage | the door opens quietly, file already present |
| Busy | a write is in flight | the field and gestures are inert; no spinner theatre |
| Opened | the file exists | question echoed, promise, wallet, gestures, entry |
| Error | the file could not be opened or a gesture could not be recorded | one plain line saying so; nothing is pretended to have been recorded |
| Denied | — | does not exist here |

The honest state worth naming: the person can ask, but nothing answers. That is the current
truth of this screen and it should not be dressed as a conversation.
