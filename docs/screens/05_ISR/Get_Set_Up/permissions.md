# Permitted roles

| Role | Relationship | Assignment | May open | Notes |
|---|---|---|---|---|
| verified member | none | none | yes | ISR is certified, not requested |
| interested user | none | none | no | must become a member first |
| founder admin | none | none | yes | reaches every area |

**Open:** whether an ISR must be attached to a Licensed Contractor company before
certification, or may certify unattached and attach later. The authority formula allows
either — nothing has ruled which (A4, A5).

**Denied state:** unwritten.
