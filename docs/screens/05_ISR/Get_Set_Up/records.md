# Permitted records

| Record | Scope | Shown | Hidden |
|---|---|---|---|
| The person's own file | self | identity, wallet balance, role holdings | everything belonging to anyone else |
| Role catalog row: ISR | public | name, summary, detail, fee | — |
| Certification modules | the ISR curriculum | title, summary, body, quiz | — |

**Not yet decided:** whether an ISR in setup sees any leads, any territory, or any company
before certification completes. Nothing has ruled it, so nothing is drawn.

Band 3 is unreachable from this screen and from every screen an ISR ever opens (A6). What an
ISR may truthfully say at a door about how an address was obtained is C35 — unanswered, and
a live risk for the curriculum written here.
