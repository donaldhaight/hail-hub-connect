# States

| State | When | What the person sees |
|---|---|---|
| Not eligible | not a verified member | the path to membership, not a refusal |
| Cannot afford | balance below the fee | the earn path; the fee is earned, never bought |
| Ready | eligible and funded | the position, the terms, and one button |
| In curriculum | begun, not finished | where they stopped |
| Failed a module | quiz not passed | **unwritten** — rules do not exist |
| Certified | complete | the ISR area, which is currently empty |
